میرا زرعی کھاتہ — Android Studio پروجیکٹ

اہم بات:
یہ Android ایپ کا تیار شدہ سورس پروجیکٹ ہے، APK فائل نہیں۔ اس ماحول میں Android SDK/Gradle build tools دستیاب نہیں، اس لیے یہاں سے APK compile نہیں ہو سکی۔

APK بنانے کا طریقہ:
1) کمپیوٹر پر Android Studio انسٹال کریں۔
2) ZIP فائل Extract کریں۔
3) Android Studio میں Open پر کلک کریں اور MyFarmLedger فولڈر منتخب کریں۔
4) Gradle sync مکمل ہونے دیں؛ ضرورت پڑنے پر Android SDK Platform 35 انسٹال کریں۔
5) Build > Build Bundle(s) / APK(s) > Build APK(s) منتخب کریں۔
6) بننے والی APK عموماً app/build/outputs/apk/debug/app-debug.apk میں ہوگی۔
7) APK موبائل میں منتقل کرکے انسٹال کریں۔ پہلی بار فون میں “Install unknown apps” کی اجازت مانگی جا سکتی ہے۔

موجودہ سہولتیں:
- ایپ آف لائن چلتی ہے۔
- کھیت، فصل، رقبہ، خرچہ، آمدن اور منافع کا ریکارڈ۔
- کھیت کی تصویر منتخب کرنے کی سہولت۔
- ڈیٹا اسی فون کی ایپ میں محفوظ ہوگا۔

اہم حدود:
- اس ورژن میں ای میل/پاس ورڈ لاگ اِن اور کلاؤڈ سنک نہیں ہے۔
- فون اور کمپیوٹر کے درمیان خودکار ڈیٹا سنک نہیں ہوگا۔
- ڈیٹا محفوظ رکھنے کے لیے ایپ کے اندر موجود JSON بیک اپ/ایکسپورٹ استعمال کریں اور فائل الگ جگہ محفوظ رکھیں۔
